# NCU AI Discovery System 評測集 v1

> 由 `eval-set-v1.json` 產生，請勿直接編輯本檔；修改請改 JSON 後執行
> `python scripts/test_course_agent/render_eval_set.py`。

- 日期：2026-11-09　題數：100　語氣：高中生口吻；保留學生原句，不替學生改寫成專業詞彙
- 涵蓋工具：14 個；不得呼叫：get_dept_info（已停用）

## 評分方式

- `checkpoints`：主指標：AI 評審逐條判斷 checks 是否達成（met / not_met，附回答原文為證據）
- `aux_8`：輔助四面向各 0–2 分：切題、正確與誠實、高中生看得懂、引導探索（不評長度）
- `hard`：程式硬指標：課名真實率、系所學程誤標、行為正確率（含 query 題的必要工具子指標）、精簡度、穩定性

## 預期行為（expected_behavior）

- `query`（應查詢）：應呼叫工具查證後回答（有任何具體線索、或明確點名系所／課程／學程／老師）
- `clarify`（應先追問）：完全沒有線索，應先追問；可不呼叫工具，但結尾必須提出問題
- `correct_premise`（應指出前提／邊界）：問題含錯誤前提、保證或超出資料範圍的要求，應明說限制或指出前提不成立；allow_no_tool 為 false 時仍須查證
- 題數：應查詢 82、應先追問 6、應指出前提／邊界 12

## 工具預期欄位說明

- `all`：每一個都必須在回答前被呼叫
- `any`：至少呼叫其中一個
- `min_calls`：指定工具至少呼叫幾次（例如比較兩個系需呼叫兩次）
- `allow_no_tool`：可以不呼叫工具（expected_behavior 為 clarify，或不需查證即可說明邊界的 correct_premise）；此時 any 不強制

## 錯誤標記

`hallucinated_course`、`hallucinated_department`、`unsupported_career_claim`、`ignored_constraint`
