# 高中生科系探索：60 題課程助理評測集

> 版本：2026-10-31  
> 對象：尚未熟悉大學科系與課程名稱的高中生  
> 範圍：中央大學科系／課程探索，不評估 Open House 功能  
> 原則：題目刻意保留生活化、模糊、跨域、錯誤前提與資訊不足等真實特徵。

## 一、使用方式

這 60 題不是全部都要求系統立刻列課程。依題目資訊量，合理的第一輪行為分成四種：

- `探索`：提出 2–4 條可能路徑，使用實際課程說明差異，再邀請學生縮小方向。
- `追問`：先問 1–2 個會明顯改變建議的問題，不應直接替學生決定科系。
- `比較`：以兩邊實際課程、知識與能力差異比較，不自行杜撰人格、薪資或職涯保證。
- `邊界`：指出資料或問題限制、糾正錯誤前提，必要時提供可查證的替代探索方向。

正式評測時，建議保留學生原句，不要先替學生改寫成專業詞彙。若要比較純向量與完整系統，兩邊
必須使用完全相同的原始問題。

## 二、題庫

### A. 極度模糊的興趣與自我描述（A01–A10）

| ID | 高中生原始提問 | 合理第一輪行為 | 主要檢查點 |
|---|---|---|---|
| A01 | 我不知道自己喜歡什麼，只知道數學不算差，可以從哪些科系開始看？ | 探索＋追問 | 不因「數學不差」只推一個理工系；用課程區分數學、物理、資工、管理等方向 |
| A02 | 我比較喜歡動手做東西，不太喜歡一直背書，中大有什麼方向適合我了解？ | 追問 | 詢問偏好機械、電子、實驗、程式或實作情境；避免宣稱某系完全不用背 |
| A03 | 我常常會注意天氣、雲和颱風，但不知道這能讀什麼。 | 探索 | 能由生活興趣連到大氣、地球科學及相關資料分析課程，並用高中生語言說明 |
| A04 | 我對電腦有興趣，可是我也不知道自己喜歡硬體還是軟體。 | 探索＋追問 | 用實際入門課程或學習內容協助辨認硬體、軟體、通訊等差異 |
| A05 | 我喜歡和人討論、做企劃，也不排斥數字，我可以先看哪些科系？ | 探索＋追問 | 不只推薦企管；應呈現管理、經濟、財金、資管等不同路徑及課程證據 |
| A06 | 我很喜歡語言和文化，可是又怕大學只是在背東西，有哪些方向可以看看？ | 探索 | 涵蓋中文、英文、法文、客家等可能路徑，以課程內容呈現分析、溝通、文化研究差異 |
| A07 | 我想做對社會有幫助的事情，但我不知道這算哪一類科系。 | 追問 | 先區分環境、教育溝通、醫療、生技、公共建設、資訊工具等問題場景 |
| A08 | 我喜歡做實驗，但物理、化學、生物好像都可以，我要怎麼分？ | 比較＋追問 | 以實驗對象、常見課程與方法比較，不以單一人格測驗式結論選系 |
| A09 | 我很愛看宇宙、黑洞和太空的影片，中央大學有哪些相關方向？ | 探索 | 從物理、太空、光電等實際課程展開；不要把科普興趣直接等同適合某系 |
| A10 | 科系名字對我來說都很抽象，可以不要先講出路，先用「大學會學什麼」帶我看嗎？ | 探索 | 回答重心放在代表課程、知識與學習活動，而非泛泛職涯文案 |

### B. 從高中學科經驗延伸（B01–B10）

|---|---|---|---|
| B01 | 我喜歡高中數學裡的機率和統計，大學有哪些科系會繼續學這些？ | 探索 | 能跨數學、統計應用、資管、財金、經濟或資料分析相關課程探索 |
| B02 | 我最喜歡物理的電路和電磁學，中大有哪些科系的課會用到？ | 探索 | 呈現電機、通訊、物理、光電等差異，課程名稱需可查證 |
| B03 | 我喜歡化學反應，也對新材料很好奇，化學系和化材系要怎麼看？ | 比較 | 以基礎化學、材料、製程或工程課程比較，避免只給抽象定義 |
| B04 | 我喜歡生物的細胞和遺傳，但不確定生命科學和生醫有什麼差別。 | 比較 | 用兩系課程與研究方法呈現差異，不武斷保證醫療職涯 |

| B06 | 我喜歡國文閱讀和寫作，但不只想讀古文，中文系還會學什麼？ | 探索 | 根據查到的課程回答；不可套用一般印象捏造數位人文或創作課 |
| B07 | 我喜歡英文，也很好奇語言是怎麼運作的，大學有哪些課可以接著學？ | 探索 | 區分文學、語言、溝通或其他實際存在的課程方向 |
| B08 | 我在高中碰過一點 Python，覺得解題很有趣，但還沒做過大型程式，可以怎麼探索？ | 探索＋追問 | 不預設一定選資工；呈現程式在資工、資管、工程、科學等領域的不同用途 |
| B09 | 我喜歡公民課談經濟和市場，也喜歡分析數據，可以看經濟、財金還是管理？ | 比較＋追問 | 以課程證據比較理論經濟、金融、企業管理及資料應用 |
| B10 | 我喜歡美術和設計，可是中大好像不是藝術大學，還有適合我的跨領域課程嗎？ | 邊界＋探索 | 誠實說明資料涵蓋與校內選項，不捏造藝術科系；可提供設計、影像、文化或跨域課程候選 |

### C. 從想解決的問題或作品反推方向（C01–C10）

| ID | 高中生原始提問 | 合理第一輪行為 | 主要檢查點 |
|---|---|---|---|
| C01 | 我想做一個可以看懂手語動作、幫助溝通的 App，大學要學哪些東西？ | 探索 | 能拆成影像辨識、機器學習、程式與使用情境；避免只列名稱相似的語言課 |
| C02 | 我想做一個判斷網路消息可不可信的工具，可以從哪些科系和課程開始？ | 探索＋追問 | 能辨識文字分析、資料、媒體理解等跨域需求；避免被「新聞」一詞帶到無關課程 |
| C03 | 我想做拍收據就能自動記帳的 App，需要同時懂資訊和會計嗎？ | 探索 | 能呈現影像／文字辨識、軟體與會計概念的跨域組合 |
| C04 | 如果我想研究地震，做更好的防災或預警，可以看哪些科系？ | 探索 | 區分地球科學、土木、資訊／感測等角色，不把預警成果做不實保證 |
| C05 | 我想用資料找出空氣污染和天氣的關係，這比較像大氣、地科還是資工？ | 比較＋探索 | 能說明領域知識與資料方法的互補關係，並提出課程路徑 |
| C06 | 我想做能幫助長輩生活的智慧裝置，應該學機械、電機還是程式？ | 追問＋探索 | 先詢問裝置偏感測、控制、結構或軟體，再給跨域組合而非單選 |
| C07 | 我對太陽能、能源和永續有興趣，中大有哪些科系的課會碰到？ | 探索 | 能跨材料、電機、物理、環境相關課程探索，說明每條路徑切入點 |
| C08 | 我想做衛星或研究太空，但不知道要讀太空系、物理還是電機。 | 比較＋追問 | 依科學研究、通訊控制、硬體等目標區分課程路徑 |
| C09 | 我想用數位工具保存客家語言和文化，可以怎麼跨領域學？ | 探索 | 能連結語言文化內容與資訊工具，避免只推薦單一系所 |
| C10 | 我想做跟健康檢測有關的科技，但我不是很確定要走生物還是工程。 | 追問＋探索 | 詢問偏生物機制、儀器感測、資料分析或材料，再提供對應課程證據 |

### D. 科系與學習方向比較（D01–D10）

| ID | 高中生原始提問 | 合理第一輪行為 | 主要檢查點 |
|---|---|---|---|
| D01 | 資工系和電機系都會寫程式嗎？實際學的東西差在哪裡？ | 比較 | 兩邊都必須有查證；用課程與能力比較，不用刻板印象 |
| D02 | 大氣科學系和地球科學系都在研究地球，它們的大學課程差在哪裡？ | 比較 | 應同時查兩系，以代表課程說明大氣與固體地球／地質方向 |
| D03 | 化學系和化材系都有化學，哪一邊比較偏實驗、哪一邊比較偏工程應用？ | 比較 | 以實際課程比例與內容謹慎歸納；若資料不足，不做絕對判斷 |
| D04 | 財金系和經濟系都會碰到錢和市場，學習重點有什麼不同？ | 比較 | 同時查兩系；不得只查一邊後憑常識補另一邊 |
| D05 | 機械系和土木系都會做工程，它們需要的數學和物理會怎麼用？ | 比較 | 以力學、設計、結構、控制等查到的課程證據比較 |
| D06 | 中文系和英文系除了使用的語言不同，大學訓練還有什麼差別？ | 比較 | 以現有課程回答，不杜撰出路或適合人格 |
| D07 | 通訊系和電機系的課會重疊很多嗎？如果喜歡網路和訊號該怎麼看？ | 比較＋探索 | 呈現共同基礎與通訊／訊號相關課程，避免把「網路」只理解為寫網站 |
| D08 | 生命科學和生醫工程，一個是不是比較研究生物、一個比較做儀器？ | 比較 | 檢查並修正學生的簡化假設，用課程證據說明重疊與差異 |
| D09 | 數學系和物理系都很重視數學，它們實際上怎麼使用數學？ | 比較 | 比較抽象數學訓練與物理模型／實驗中的使用方式 |
| D10 | 企管系和資管系差一個「資」而已嗎？如果喜歡企劃也喜歡科技該怎麼選？ | 比較＋追問 | 用管理與資訊相關課程比較，再追問偏組織／市場或系統／資料 |

### E. 帶有背景、限制、焦慮或迷思（E01–E10）

| ID | 高中生原始提問 | 合理第一輪行為 | 主要檢查點 |
|---|---|---|---|
| E01 | 我是社會組，但最近對資料分析很有興趣，也沒學過程式，還有哪些方向可以開始？ | 探索 | 不因類組排除可能性；提出由入門數學、統計或程式逐步探索的課程 |
| E02 | 我是自然組，可是其實很喜歡寫作和語言，選文學院會不會浪費高中學的東西？ | 邊界＋探索 | 不接受「浪費」前提；呈現跨域運用方式，但不做空泛安慰 |
| E03 | 我數學沒有很好，但很想碰 AI，是不是就不能讀相關科系？ | 邊界＋探索 | 不做絕對否定或保證；具體指出相關基礎課程與可先測試的學習內容 |
| E04 | 我從來沒寫過程式，如果選資工是不是一定跟不上？ | 邊界＋探索 | 不替全體學生下結論；說明可查到的入門與基礎課程，以及可先嘗試的方法 |
| E05 | 我不一定想讀資工，但想學 Python 和資料分析，有其他科系或學程嗎？ | 探索 | 應跨系搜尋實際課程與學程，不把程式學習限定在資工 |
| E06 | 我比較想做專題和實作，不喜歡只有理論，哪些方向可以先看？ | 追問 | 「實作」太廣，先區分實驗、工程製作、程式專案、田野或商業企劃 |
| E07 | 我現在只是高中生，不想看到一堆研究所課，可以先給我大學部能理解的方向嗎？ | 探索 | 排除研究所限定課程；用少量代表課程與白話解釋，不傾倒完整清單 |
| E08 | 我很容易每個領域都覺得有趣，不想太早選死，可以怎麼找跨領域課程或學程？ | 探索＋追問 | 先找共同主題，再提供跨域課程／學程；不要一次列出全校所有選項 |
| E09 | 我想找比較簡單、比較好拿分的科系，可以直接推薦嗎？ | 邊界 | 說明缺乏客觀難度與成績資料，不能保證；轉為探索學習內容與適配需求 |
| E10 | 家人希望我讀電機，但我比較喜歡生物，我可以先比較哪些課再決定？ | 比較＋探索 | 尊重學生自主；以電機、生物、生醫交界課程協助探索，不代替決定 |

### F. 資訊不足、錯誤前提與系統邊界（F01–F10）

| ID | 高中生原始提問 | 合理第一輪行為 | 主要檢查點 |
|---|---|---|---|
| F01 | 哪一個科系畢業後薪水一定最高？ | 邊界 | 不提供保證；說明課程資料無法推導個人薪資，可改問學習內容與能力方向 |
| F02 | 中大哪個科系最容易畢業？ | 邊界 | 不用傳聞或主觀印象回答；缺乏一致的難度／畢業率證據時應拒絕排名 |
| F03 | 我喜歡科技，你直接告訴我最適合哪個系就好。 | 追問 | 「科技」過廣，至少追問想理解、製作或解決的問題，不直接單押一系 |
| F04 | 中大法律系有哪些跟科技法律有關的課？ | 邊界 | 先核對是否存在該系；不存在時不可自行補成相近系名或捏造課程 |
| F05 | 中大心理系如果想走 AI，有哪些課可以修？ | 邊界 | 核對系所存在性；查無時說明限制，再提供「心理／人類行為＋AI」的可查證替代方向 |
| F06 | 幫我從高中開始排到大四，保證我可以成為 AI 工程師。 | 邊界＋追問 | 拒絕保證；指出缺少背景、入學科系與未來課表資訊，可先提供探索性基礎路徑 |
| F07 | 我想學所有跟人工智慧有關的課，全部列給我。 | 探索＋追問 | 說明範圍很大，先分入門、數學、程式、應用領域並確認學生想看哪一類 |
| F08 | 量子電腦聽起來很酷，我應該讀資工、物理還是光電？ | 比較＋追問 | 以目前查到的課程確認各路徑，先問偏理論、硬體／光學或演算法，不追逐熱門詞 |
| F09 | 我好像什麼都喜歡，也什麼都不排斥，那你可以推薦全部嗎？ | 追問 | 不傾倒大量清單；用二選一情境或活動偏好逐步縮小範圍 |
| F10 | 我討厭數學但想讀資工，資工是不是其實不用數學？ | 邊界＋探索 | 糾正「不用數學」前提，以實際基礎課程說明數學用途，同時避免斷言一定不適合 |

## 三、建議人工評分規準

每題六個面向，各給 `0–2` 分，滿分 12 分。評審者應先看到工具／檢索結果，再判斷回答是否有根據。

| 面向 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 證據正確性 | 捏造或與資料衝突 | 大致正確但部分缺乏依據 | 具體敘述均可由查到的課程／規定支持 |
| 探索相關性 | 明顯偏題 | 部分方向相關 | 能抓到學生真正想探索的核心問題 |
| 範圍與多樣性 | 只給單一路徑或亂列 | 有多條路徑但差異不清 | 2–4 條互有差異且有理由的路徑 |
| 澄清與不確定性 | 資訊不足仍武斷回答 | 有提醒但追問無關鍵性 | 在必要時提出 1–2 個會改變建議的關鍵追問 |
| 高中生可理解性 | 充滿術語或直接倒課名 | 有解釋但仍偏大學內部語言 | 用生活化語言解釋課程在學什麼及為何相關 |
| 下一步可行性 | 沒有可執行下一步 | 只說「再多了解」 | 提供可比較課程、下一個追問或具體探索方法 |

### 額外錯誤標記

下列錯誤另以布林欄位記錄，方便統計失敗類型：

- `hallucinated_course`：出現檢索結果沒有的課程名稱。
- `hallucinated_department`：出現不存在或未查證的系所。
- `unsupported_career_claim`：宣稱薪資、就業、適合人格或職涯保證但無資料支持。
- `premature_single_recommendation`：模糊問題尚未澄清就只推薦一個系。
- `overwhelming_list`：對高中生一次傾倒大量課名，沒有分群與解釋。
- `missed_clarification`：題目資訊不足，卻沒有提出能改變方向的追問。
- `ignored_constraint`：忽略學生說的類組、程度、希望大學部、跨域等限制。

## 四、統計建議

不要把所有題目只算成單一「答對率」，因為模糊題可能沒有唯一標準答案。建議至少分開報告：

1. A、E、F 類：平均人工品質分數、必要追問成功率、過早單一推薦率。
2. B、C 類：課程證據支持率、跨域覆蓋率、幻覺率。
3. D 類：雙邊都有查證的比例、比較是否使用實際課程證據。
4. 全體：無依據課程率、無依據系所率、平均延遲、P95 延遲與單次成本。
