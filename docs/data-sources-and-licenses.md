# 資料來源、授權與衍生內容政策

本文件記錄目前正式執行路徑所使用的資料、衍生方式與待確認事項，供比賽審查及後續維護使用。

## 系所介紹

`ncu_departments` 的正式內容與向量策略尚未決定。目前採取 fail-closed：

- `get_dept_info` 不在 agent 的 Function Schema 與工具執行路由中。
- 即使直接呼叫保留函式，也只會回傳停用訊息，不查詢 Qdrant。
- 系所名稱解析不再以 `ncu_departments` 作為向量 fallback。
- 全量索引建置會跳過 `ncu_departments`。
- 比較科系時，只能根據現有課程、概念、技術與核心能力資料，不產生未經證實的系所特色或生涯描述。

`data/raw/collego_ncu.json` 與 `scripts/scrapers/scrape_collego.py` 是舊版研究產物，已退出正式索引流程。
在未取得可涵蓋重製、建立檢索索引及公開展示的明確授權前，不得重新接回正式服務或更新資料。

既有 Qdrant collection 即使尚未刪除，也沒有 agent 執行路徑會讀取；待 review 完成後再決定重建或移除。

## 國科會大專學生研究計畫成果報告

### 已確認事項

- 資料來源：國家科學及技術委員會「學術補助獎勵查詢」的大專學生研究計畫成果報告。
- 原始查詢頁：<https://wsts.nstc.gov.tw/STSWeb/Award/AwardMultiQuery.aspx>
- [國家科學及技術委員會補助大專學生研究計畫作業要點](https://law.nstc.gov.tw/LawContent.aspx?id=GL000114&kw=)
  第十二點規定，成果報告原則上應供立即公開查詢；涉及專利、其他智慧財產權或論文尚未發表者，
  得延後公開最長二年，期滿後自動公開。此規定可以證明公開查詢義務，但未明文授權第三人重製、改作、
  重新上傳、建立向量索引或開發公開服務。
- [國科會政府網站資料開放宣告](https://www.nstc.gov.tw/folksonomy/detail/a22a29a9-03d7-4d55-850a-f4f6ca1a04e9?l=ch)
  表示國科會網站上刊載且在其授權範圍內的資料與素材採「政府資料開放授權條款－第 1 版」發布，
  但同時排除另有特別聲明的專人專案撰文及其他著作。
- [政府資料開放授權條款－第 1 版](https://data.gov.tw/license) 將「開放資料」限定為資料提供機關
  擁有完整著作財產權，或已取得可再授權第三人利用之權利的資料。
- 確認日期：2026-10-31。

目前尚未找到足以確認「學術補助獎勵查詢」中由學生或其他作者提交的成果報告，均屬國科會得依政府資料
開放授權條款再授權之資料。公開查詢不等於開放授權，因此不能僅依上述兩項規定推論本專案可將全文下載保存、
重新上傳至 Cloudinary、建立向量索引、用於 RAG 或公開展示，也不能記載為「無須向作者取得授權」。

### 目前處理原則

1. 在取得國科會或權利人的書面確認前，不把成果報告全文重製、重新上傳、全文向量化及公開展示記載為已獲授權的正式資料流。
2. 已公開的計畫名稱、年度、執行機構等事實性欄位，仍須記錄來源並另行檢查個人資料及平台使用條件。
3. 必要的少量引用應明確標示出處、作者與引用範圍，且不得以「公開查詢」取代合理使用或其他合法利用依據的個案判斷。
4. AI 摘要、分類、標籤、題目與回答均須標為本專案衍生內容，不得表示為作者原文或原作者結論。
5. 不得暗示本系統、AI 衍生內容或服務獲得國科會、原作者或國立中央大學的認可或背書。
6. 下一步應向國科會確認成果報告是否適用政府資料開放授權條款，以及該授權是否涵蓋全文下載保存、
   第三方雲端公開傳輸、文字與資料探勘、向量索引、AI 檢索及公開競賽展示。

在授權範圍確認前，不使用宣稱成果報告已依政府資料開放授權條款釋出的對外標示文字。

## 開放資料標示原則

若採用政府資料開放平臺資料，逐筆記錄：

1. 資料集名稱及提供機關。
2. 來源網址與下載／更新日期。
3. 適用的授權條款版本。
4. 必要的顯名聲明。
5. 本專案做過的清理、統計、推論或摘要。

「網站公開可閱」不等於「開放授權」。若來源頁沒有明確授權，僅擷取必要的事實性欄位，避免重製
介紹段落、照片、圖表、影音、校友故事或其他具創作性的內容，並保留可追溯的來源紀錄。
